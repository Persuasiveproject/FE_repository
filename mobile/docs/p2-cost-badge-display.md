# P2 비용 정보·다음 배지 표시

기능 기준: FC-MK-120-002, FC-MY-110-001 및 배지 기준 FC-MY-110-002. 기존 API 수정1의 API #45와 #6 응답을 사용하며 서버 필드·경로·오류 코드를 추가하지 않는다.

## 구현

- 게시 전 비용 확인 단계에서 `GET /v1/me/wallet`의 `data.coinBalance:integer`를 인증 조회한다. 필요한 코인은 기존 규칙의 1개이며, 잔액이 충분하면 게시 후 예상 잔액을 계산한다.
- 조회 중·실패 시 임의 잔액으로 대체하지 않는다. 잔액이 0이면 게시 버튼을 막고 작성 상태는 유지한다. 화면 재진입 시 잔액을 다시 조회한다. 게시 시점의 최종 잔액 검증은 기존 게시 API가 수행한다.
- 기존 `/v1/me`의 소수 6자리 `credit`를 사용해 다음 기준 40점(관점 탐험가) 또는 55점(생각 연결자)까지 남은 점수를 계산한다. 표시 계산은 정수 마이크로 점수로 수행해 작은 잔여 점수가 0으로 반올림되지 않도록 한다.
- 55점 이상은 최상위 배지 점수 기준에 도달했다는 안내만 표시한다. 배지 지급·획득 기록을 생성하지 않는다.

## 이번 변경에 포함하지 않은 항목

- 게시 한도의 미등록 오류 코드, 주간 충전의 미등록 원장 유형·대상 회원 정책은 추가하지 않았다. 사용자가 새 계약 제안을 승인하지 않고 기존 명세만 적용하도록 요청했다.
- 크레딧 내역의 변경 후 점수·토론별 보상 합산은 기존 API 계약의 별도 미해결 사항이다. 이번 변경은 이를 완료한 것으로 간주하지 않는다.
- 크레딧 내역 20개 커서 페이징은 BE PR #47의 기존 구현을 사용한다. 해당 PR은 별도 통합 검증 대상이며 이번 FE 변경에서 내역 응답 필드를 확장하지 않는다.

## 검증 범위

`tests/p2-display.test.ts`에서 40·55점 경계, 소수 6자리, 잘못된 점수, 0코인, 잔액 타입 오류·인증 실패 및 실제 API 경로와 헤더 사용을 검사한다. HTTP 응답은 테스트 fixture이며 실제 배포 서버 인증을 검증한 것은 아니다.
